
SPRINT 15 — PÁGINA SERVIÇOS ENTERPRISE

Arquivos incluídos:
- app/servicos/page.tsx
- app/servicos/servicos.module.css

INSTALAÇÃO

1. Copie a pasta "app" para a raiz do projeto.
2. Confirme a substituição somente da pasta:
   app/servicos

3. Execute:
   npm run dev

4. Teste:
   http://localhost:3000/servicos

DEPENDÊNCIA

A página utiliza "lucide-react", que já vinha sendo usada nas sprints anteriores.

Caso apareça erro de módulo não encontrado:
npm install lucide-react

A página contém:
- Hero comercial
- Seis cards de serviços
- Fluxo de atendimento
- Diferenciais
- Comparativo sem vistoria x com Visão Classe A
- Públicos atendidos
- CTA final
- SEO da página
- Layout responsivo
