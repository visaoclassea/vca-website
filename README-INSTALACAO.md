# Sprint 7 — Home Premium

## Arquivos incluídos

- `app/page.tsx`
- `app/home-premium.module.css`
- `public/images/hero.png`
- `public/images/fabricio.png`
- `public/images/logo.png`

## Instalação

1. Faça backup dos arquivos atuais.
2. Copie as pastas `app` e `public` para a raiz do projeto.
3. Confirme a substituição de `app/page.tsx`.
4. Rode:

```bash
npm run dev
```

5. Abra `http://localhost:3000`.

## Observações

- O `Header` e o `Footer` existentes continuam sendo usados pelo `app/layout.tsx`.
- A página não altera nenhuma rota ou API do Pix.
- O CSS está isolado em módulo, evitando conflito com o `globals.css`.
